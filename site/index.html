视频远在天涯

B 站的视频节点大多在国内。人在海外时，每一段数据都要跨洋往返；播放器只缓冲眼前几秒，网速一抖就开始转圈。

海内存知在播放器开口之前，就把前方的分段取回本机。进度条上橙色的一段，就是已经在身边的部分。

存在身边

从你点下播放开始，海内存知就在后台把视频一点点装进瓶子里。

播放时提前加载

取得播放器的第一个请求后立刻预热前方分段。本机数据完整命中就直接交给播放器，不命中自动回退原始请求，不会把播放弄坏。

一键完整缓存

按账号实际可用的最高画质下载，音视频在本机合并为 MP4，不转码；也可以只缓存保留原始音质的音频（Hi-Res 无损 / 杜比全景声 / AAC）。

关掉页面也继续

下载在后台独立进行。断网、地址过期或被限流时自动刷新并从断点续传；暂停之后随时继续，不必重新打开视频。

  • 需要带走时，一键保存为本地 MP4 或音频文件

天涯亦有知己

B 站是我们自己的地方：同样的梗、同样的弹幕、同样的知识底子。人在海外，最懂你的还是这里的同胞。海内存知做的，只是让这段距离不再转圈。

只有你知道

海内存知没有服务器。它记得的一切，都只留在你自己的浏览器里。

没有服务器

不收集、不上传任何数据；没有统计、埋点，也没有广告。

登录态只看「有没有」

只判断是否已登录，用来显示可用画质；从不读取 Cookie 的值。

数据留在本机

缓存与设置都在你的 Chrome 配置里；删除缓存或卸载扩展即可清除。

开源可查

每一行代码都在 GitHub 上，发布包可以按源码复现校验。

阅读完整的隐私说明。这个网站同样不使用 Cookie、统计或任何第三方资源。

能做什么，不做什么

  • 支持标准 BV / av 投稿、分 P，以及带 bvid 的稍后再看页面；番剧、互动视频和课程暂不支持。
  • 不绕过任何会员、付费、地区或内容授权限制，只使用账号本来就有的观看与画质权限。
  • 需要 Chrome 116 或更高版本。请只缓存你有权观看的内容，并遵守平台条款与版权要求。

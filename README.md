# Bili 缓冲站

面向海外网络环境的 Chrome Manifest V3 插件。它会通过当前 B 站页面的登录会话读取实际可用画质，默认选择最高一档；单文件 MP4 直接分块保存，高画质 DASH 则分别缓存视频轨和音频轨。再次打开相同视频与分 P 时，插件会校验缓存，并在原网页播放器中使用 Blob 或 MediaSource 本地播放，保留 B 站的控制条、倍速、进度与弹幕同步。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 选择“加载已解压的扩展程序”，选择本项目文件夹。
4. 打开标准 B 站视频页（`https://www.bilibili.com/video/BV...`）或带 `bvid` 的稍后再看页面，点击工具栏中的插件图标。

## 使用

- 在“缓存画质”中选择清晰度；首次打开默认选中 B 站返回的最高可用画质。
- 同一标签页的插件弹窗关闭后，再次打开会直接恢复上次的视频信息、画质和选择；快照过期时也会先显示旧状态、再在后台更新。
- 点击居中的“缓存”按钮缓存当前视频或当前分 P。不同画质使用独立缓存键，已有低画质不会阻止继续缓存更高画质。
- 下载前会用小范围请求比较主 CDN 与备用 CDN，然后以最多 3 路、2 MiB 固定范围并发缓存；某个分块超时或中断会自动保持同一范围切换节点，不会把半块写入本地。
- 缓存任务开始后可以关闭弹窗、切换标签页，或关闭原视频页；下载由扩展的 Offscreen Document 继续执行。扩展重载时会优先刷新地址，原页不可用时改用任务中保存的 CDN 候选地址续传。
- 点击当前视频或片库中的 UP 主名称会打开其 B 站主页；在下方列表点击标题会打开原视频，完成项目的下载箭头会保存文件，垃圾桶按钮会删除缓存。
- 单文件缓存保存为一个 MP4；高画质 DASH 是 B 站返回的独立视频轨和音频轨，当前会分别保存为 `.视频轨.mp4` 与 `.音频轨.m4a`，避免生成看似成功但实际无声的文件。
- 再次打开已经缓存的视频时，插件会自动切换到本地 MP4；控制台会记录“已切换为本地缓存播放”。
- 扩展只为自身发往 B 站视频 CDN 的下载请求补充 B 站 `Referer`，以满足 CDN 防盗链校验；不会修改其他网站的请求。
- 只有实际写入字节数与 CDN 报告的完整文件大小一致时，视频才会标记为“已缓存完成”。
- 播放地址优先由当前 B 站页面发起，以便使用该页面的真实登录会话；失败时才回退到扩展后台请求。扩展只读取 `SESSDATA` 是否存在来显示登录状态，不展示、复制或保存 Cookie 原始值；大会员内容能否访问仍以当前账号的实际权益和 B 站返回结果为准。

## 开发态热更新

安装依赖不是必需的。加载本目录中的未打包扩展后，在项目目录运行：

```bash
npm run dev
```

热更新服务会监听扩展的 JS、JSON、HTML、CSS 与图标文件。扩展通过仅绑定本机的开发端点检查修订号，变化后约 1 秒内执行 `chrome.runtime.reload()`。固定的 manifest 公钥保证扩展 ID 稳定；原位重载不会清除 IndexedDB，已经缓存的视频会保留，未完成下载会从最后一个已持久化分块自动续传。

不要删除 manifest 中的 `key`，也不要手动清除扩展存储；这两项分别关系到扩展身份和缓存数据连续性。发布到 Chrome Web Store 前应移除开发态热更新模块与 `127.0.0.1` 权限。

## 当前边界

- 支持标准 BV / av 投稿、分 P 和带 `bvid` 的稍后再看页面。番剧、互动视频、课程和特殊分段格式会显示不支持，不写入伪缓存。
- 画质选项只显示播放接口实际返回媒体轨道的档位，并按清晰度降序排列；不会把接口仅声明、但没有返回轨道的画质列为可缓存。
- 支持单段 progressive MP4，以及 Chrome MediaSource 能播放的 DASH 视频/音频 MP4 轨；不支持的编码、番剧和特殊多段格式会明确提示。
- 登录 Cookie 只能尝试恢复当前账号本来就有的观看和画质权限，不能绕过大会员、付费、地区或内容授权限制。
- Chrome 不提供把两个 DASH Blob 自动合并成单个 MP4 的扩展 API；当前保存按钮对 DASH 采用双轨导出，本地缓存播放仍会把两轨同步播放。
- 缓存仅保存在当前 Chrome 配置中；卸载扩展会删除缓存。
- Popup 界面快照使用 `chrome.storage.session`；浏览器重启、扩展禁用/重载，或首次打开某个视频时，仍需重新读取当前真实画质。
- 并发下载能绕开某些 CDN 的单连接限速，但不会突破当前网络总带宽；实际提速取决于视频节点、时段和跨境路由。
- 只应用于用户有权观看的内容，并应遵守平台条款与版权要求。

# 缓存架构改进验收账本

基线：`995f111` 图标身份；`4a5c7fb` 完整 2.8.0 在线救援与既有实测策略。每项源码、测试、版本及文档在同一个提交；每次提交前 `npm test && npm run check && npm run build`，不提交 dist 或调试日志。

| 项目 | 核心验收 | 状态 |
| --- | --- | --- |
| 1 收益驱动并发 | 重复有效样本才试探；无收益收缩、收益下降回退、后续可扩容；不突破用户上限；旧/救援/快速样本不学习 | 2.8.1：单元/下载集成通过；现有 Chrome 实测并发 8→4→8，字节正确 |
| 2 跨上下文预算 | 多标签与离线请求共享租约；播放优先；取消/超时/重启不泄漏预算 | 2.8.2：持久账本/生产桥接测试通过；现有 Chrome MessageChannel 双客户端峰值 2、释放后 0 租约 |
| 3 缺口复用 | 部分命中只请求缺口；校验与世代失败不伪装命中 | 2.8.3：生产 fetch/XHR/观察器 VM 与现有 Chrome 原生类型验证；兄弟取消及向后 seek 回归通过 |
| 4 播放感知回收 | 保留临近播放数据和初始化区；远离窗口先回收；容量上限真实有效 | 2.8.4：SIDX/比例回退与观察器整链通过；现有 Chrome 保留近端/回收远端且不超上限，关闭模式不重建提示 |
| 5 有界内存 | 在线有界在途字节；离线有界乱序窗口/背压；失败唤醒等待者 | 2.8.5：慢首块/慢事务/失败/取消及拼接压力测试通过；现有 Chrome 六任务排队、峰值预留 48 MiB、reset 后归零 |
| 6 持久缓存复用 | 严格媒体身份/签名/总长/账户隔离；合并文件不能充当源范围；双向复用有界 | 2.8.6：镜像/桥/观察器整链与身份纯函数通过；现有 Chrome 真实 IndexedDB 验证跨主机复用、孔洞与账户隔离、清理 |
| 7 兼容与回退 | 不支持能力直接原生；重复安装、失败熔断、取消、桥接失败安全降级；默认配置一致 | 2.8.7：能力缺失/重复安装与写入/熔断/迟到回包/取消顺序/默认配置与权限均有回归；观察器在缺少 MutationObserver 时仍可加载 |

浏览器验证只能连接用户现有的 Chrome。区分真实 CDN 速度实验与真实浏览器中的受控正确性探针，不把后者当作测速。无法验证的环境/边界必须保留为未完成，不把构建成功当作浏览器证据。

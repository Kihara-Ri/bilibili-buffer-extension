设计：[最终设计](../specs/2026-10-26-github-updater-design.md)。

1. 签名协议：版本、固定来源、受限文件路径、逐文件哈希、清单权限／身份保持。先观察失败测试，再实现。已完成核心单测。
2. 文件事务：绑定真实运行目录、预备份、manifest 最后写、读回校验与恢复。已完成核心单测。
3. 渠道构建：商店移除更新实现与网络权限，GitHub 保留 key 和更新入口，签名 JSON 与 ZIP 同快照。开发者显式初始化并保管发布密钥，测试使用临时根。
4. 运行协调：storage 持久锁、保存冲突、offscreen 闸门、暂停清单、重载续接／健康检查与恢复。更新页与弹窗链接、中英文。
5. 验收：真实隔离 Chrome 验证目录写入／重载及数据保留；全量 check/test/popup/build；文档说明两渠道及未验范围。最后独立审查并修复重要问题。

片库跨安装迁移、官网目录授权、商店内核或隔离模块热更新均不属于此方案。
